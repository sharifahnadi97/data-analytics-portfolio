# Coffee Shop Sales Analysis

## Project Overview

This project analyses coffee shop sales data from 2023 to 2025 to understand sales performance, profitability, product performance and regional trends. SQL was used to combine, clean and transform the data, while Power BI was used to create an interactive dashboard and present key findings.

## Tools Used
- SQL Server
- Power BI: Power Query, DAX

## Objectives
- Analyse total revenue and profit
- Calculate profit margin
- Explore sales trends over time
- Analyse revenue by product category
- Compare sales performance across regions
- Identify trends in sales performance from 2023 to 2025
- Present key findings through an interactive dashboard

## SQL Analysis
The SQL analysis includes:

- Combining sales data from 2023, 2024 and 2025
- Joining order, customer and product tables
- Handling missing revenue values
- Calculating cleaned revenue
- Calculating profit
- Filtering invalid customer records
- Creating a reusable SQL view for Power BI

## Power BI Dashboard
The dashboard provides an interactive overview of coffee shop sales performance from 2023 to 2025.

Key metrics and analysis include:

- Total revenue
- Total profit
- Profit margin
- Total COGS
- Average revenue
- Customer count
- Revenue by product category
- Revenue trends by region
- Yearly and quarterly performance

## Key Insights
- Total revenue from 2023 to 2025 was approximately RM871K.
- Total profit was approximately RM478K, resulting in a profit margin of 54.84%.
- Grinders & Brewers generated the highest share of revenue among the product categories.
- Revenue performance varied across regions and over time.
- The yearly and quarterly breakdown highlights changes in regional sales performance throughout the period.
