# COVID-19 Data Analysis

## Project Overview

This project analyses global COVID19 data to explore the spread and impact of the pandemic across different countries and regions. The analysis focuses on reported cases and deaths, trends over time, and comparisons between countries. The results are presented using SQL analysis and an interactive Power BI dashboard.

## Tools Used
* SQL
* Power BI: Power Query, DAX

## Objectives
* Analyse global COVID19 cases and deaths
* Explore trends over time
* Compare cases and deaths across countries
* Identify key trends and patterns in the data
* Create an interactive Power BI dashboard
* Present findings clearly through data visualisation

## Analysis
The project covers:
* Total cases
* Total deaths
* New cases and deaths over time
* Cases and deaths by country
* Country comparisons
* Key performance indicators
* Time-series analysis

## Power BI Dashboard
An interactive Power BI dashboard was created to explore COVID19 cases, deaths, and trends across different countries and time periods.


## Key Insights
* COVID19 cases and deaths varied considerably across countries and regions.
* Reported cases and deaths changed significantly throughout the pandemic.
* Time-series analysis highlights periods of rapid increases and decreases in reported cases.
* Country-level analysis shows differences in the scale and progression of the pandemic.
